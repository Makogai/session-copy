# Session Copy v2.2.0

**Site cleanup & build pipeline**

### Added
- **Clear site data** — remove cookies, `localStorage`, and `sessionStorage` for the active tab (useful after a bad paste/restore).
- Dedicated **Clear** tab in the popup, plus matching shortcuts on **Home** and **Settings**.
- **npm + esbuild** build: source in `src/`, load **`dist/`** in Chrome; store ZIP from **`release/`**.

### Fixed
- Session **copy** after minified release builds (injected storage reads use `window.localStorage` / `window.sessionStorage`).
- Bottom navigation layout with four tabs.

### Changed
- GitHub Actions release workflow packages via `npm run package` (esbuild output).

**Full changelog:** https://github.com/Makogai/session-copy/blob/main/CHANGELOG.md
