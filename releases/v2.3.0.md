# Session Copy v2.3.0

**Vue UI, themes & refreshed site**

### Added
- **Vue 3 + TypeScript popup** — Home, Clear, Settings, and Info; easier to extend going forward.
- **Light / dark themes** — follows your system by default; choose System, Light, or Dark in Settings.
- **Clear site data** — dedicated tab to wipe cookies and storage for the active site (for bad restores).

### Changed
- **GitHub Pages site** — light/dark themes, fuller feature list, corner version badge.
- Service worker and content scripts remain JavaScript; session capture/restore behavior unchanged.

### Developers
- `npm run typecheck` — Vue/TS check for the popup.
- `npm run build` syncs `docs/version.json` from `package.json`.
