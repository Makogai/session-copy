# Session Copy v2.0.0

**Offline-first sessions**

### Breaking / major
- **Removed Firebase** — sessions are encrypted and stored only on your device (clipboard or `.session` file).
- New encrypted format: `sc:v2:` (gzip + AES-256-GCM).

### Added
- Automatic **file export** when the clipboard token would be too large.
- **Login transfer** mode — smaller payloads focused on auth cookies and keys.
- Import/export encrypted `.session` files.

### Fixed
- **HttpOnly cookies** restored via `chrome.cookies.set` (service worker).
- Early storage injection + tab reload for better login restore (e.g. ChatGPT).
